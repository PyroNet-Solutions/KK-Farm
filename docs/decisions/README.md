# Decision records

Long-form Architecture Decision Records go here as `D-xxx-short-slug.md` when a row in [../DECISIONS_LOG.md](../DECISIONS_LOG.md) needs more than a sentence of rationale. The log is the index; this folder holds the detail.

Template:

```
# D-xxx: Title
Date · Status (Proposed / Accepted / Superseded)
## Context
## Options considered
## Decision
## Consequences
```
