# Farm Data Capture Templates

Blank, fill-in templates for the on-site visit. **Structure only — never put real names, phone numbers, ID numbers or actual financial figures in Git.** Use codes (`EMP-01`, `VET-1`, `SUP-01`, `SHED-1`, `PEN-1A`). Copy a template as many times as needed. Tag every row: **C** = Confirmed · **O** = Observed · **R** = Reported · **A** = Assumed · **U** = Unknown.

Each template ends with a *Notes / unexpected findings* box.
